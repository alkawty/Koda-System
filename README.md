# نظام كودا | Koda-System  
*نبذة : هذا هو عبارة عن نظام محاسبي متكامل ERB ، بلغة #C على بيئة Windows Framework.
#
# هيكلة الملفات :
1- Fonts -- مجلد فية خطوط الذي مضمنة في المشروع 

2- DataBase -- هذا المجلد فقط يحتوى ع ملف نصي فية الجداول الذي قد قمت بتضمينها في المشروع

3- Project File -- هذا المجلد فية جميع ملفات المشروع الاساسية 
# طريقة تشغيلة :
* بعد تحميل ملفات هذا المستودع قم بفك الضغظ عنة.
* بالاول قبل ما تفتح المشروع قم بتثبيت الخطوط الذي ف مجلد Fonts، لكي يضهر لك بنفس التنسيق المطلوووب.
* ثانيا افتح المشرو،كيف؟ تروح لمجلد Project File بتحصل ملف بإمتداد sln انقر علية مرتين وهو عينفتح ديفولت في فيجول ستيديو.
* ثالثا قم بفتح كلاس حق قواعد البيانات DBase، وغير نص الاتصال الى نص الاتصال بقاعدتك الذي في جهازك <br>
> [!WARNING]
> Note :  SQL SERVER هنا الاتصال بقاعدة بيانات ع


*  رابعا قم بإنشاء الجداول الذي موجودة في ملف DataBas ؟ تروح تنشى هذة الجداول ع قاعدة بيانات الذي متصل فيها.
*   خلاص هنا كل شي جاهز، عدل ، افتح ، اطرح افكارك ، ناقش.
